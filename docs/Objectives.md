# Project Objectives

The primary objective of MedGuardian AI is to develop an intelligent AI-assisted patient monitoring system that continuously observes hospitalized patients and provides early warning alerts to healthcare professionals when potential signs of patient deterioration are detected.

## Specific Objectives

- Detect patients from live hospital camera feeds.
- Identify and track individual patients continuously.
- Analyze facial expressions to estimate pain or distress indicators.
- Monitor eye status for prolonged closure or reduced responsiveness.
- Analyze body posture and detect abnormal positions.
- Monitor patient movement and inactivity over time.
- Extract meaningful visual features using Computer Vision techniques.
- Predict patient risk levels using Machine Learning models.
- Provide Explainable AI outputs that justify each prediction.
- Generate intelligent multi-level alerts based on risk severity.
- Display real-time patient status through an interactive dashboard.
- Maintain monitoring history for future clinical review.
- Design the system as a clinical decision-support tool that assists healthcare professionals rather than replacing them.
