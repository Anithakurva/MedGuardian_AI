# Project Scope

## Included

- Patient Detection
- Patient Tracking
- Facial Expression Analysis
- Eye Monitoring
- Pose Estimation
- Movement Analysis
- Risk Prediction
- Explainable AI
- Multi-Level Alert System
- Hospital Dashboard
- Monitoring History
- Real-Time Processing

## Not Included

- Disease Diagnosis
- Medicine Recommendation
- Surgery Recommendation
- Medical Prescription
- Replacing Doctors or Nurses
- Autonomous Medical Decision Making

The system is intended only to assist healthcare professionals by providing continuous monitoring and intelligent early warning alerts.
